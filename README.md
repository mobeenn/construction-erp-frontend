# Build Flow — Frontend

Vite + React 19 SPA for the Construction ERP.

```bash
npm install
# Ensure .env has VITE_API_URL=http://localhost:5000/api
npm run dev      # http://localhost:5173
npm run build    # production bundle → dist/
```

Backend must be running on port 5000 (or match `VITE_API_URL`).
See the root [README](../README.md) for full local setup.
